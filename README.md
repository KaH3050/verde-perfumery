# Verde Perfumery

Concept perfume store by [KYNEX](https://kynex.kynex-sites.workers.dev) — example of the **Basic e-commerce** plan. Fictional Miami brand.

- Hero carousel with three featured fragrances (notes, size, price, add to bag)
- Collections (for her, for him, unisex, gift sets), 12 products with filters and sorting
- Product page with notes pyramid, 30/50/100 ml sizes, quantity and a shareable link (e.g. `#nuage-rose`)
- Saved bag with free-shipping progress; checkout sends the order on WhatsApp
- Two-question scent finder, favorites tab, newsletter
- English by default, Portuguese with one tap; tested at 1440 px and 390 px
- Plain HTML, CSS and JavaScript, no build step; product photos are AI-generated: bottle cut-outs in `img/bottles/`, plus gift set photos (`img/trio.webp`, `img/discovery.webp`), the Oud Prune banner (`img/oud-banner.webp`), `img/about.webp`, one backdrop per fragrance (`img/scenes/`, the bottle is placed on the pedestal in code) and cut-out flowers with falling petals (`img/flowers/`)

**Português:** loja-conceito de perfumes Verde Perfumery da KYNEX (plano E-commerce básico). Pedido finalizado pelo WhatsApp.
